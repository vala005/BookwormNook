# Bookworm's Nook

i want to create a book tracker website. the layout will a bookshelf background and when you add a book you can input the start/finish date, rating out of 5, add tag (genres/themes). once you click a book on a shelf it will display the information listed above. there will also be a menu at the top with bookshelf and dashboard. dashboard will consist of reading statistics pages per day, preferred genre, other statistics. i would like a dark academia theme to this page. i have attached the logo for the site it is called bookworm's nook.
